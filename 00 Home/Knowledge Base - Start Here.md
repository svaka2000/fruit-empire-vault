# Knowledge base: start here

Samarth's own notes on how Fruit Empire is made: the look, the map, the tools, the rules the chats follow, and one page per project. Written on 8 Nov 2026 from the handoffs repo, Claude's memory files and the project repos. Back to [[Fruit Empire - Home]].

> [!important] The handoffs repo is the shared truth
> Samarth, Weilin and both Claudes read the private GitHub repo `svaka2000/fruit-empire-handoffs`. These notes **link** to its pages instead of copying them, and add what the repo does not hold. Where they disagree, the repo wins. Start with [[Handoffs Repo Links]].

> [!warning] This folder is a public git repo
> The `Fruit Empire/` folder pushes to `github.com/svaka2000/fruit-empire-vault`, which is public. The 8 Nov notes were pushed there at Samarth's go. Keep secrets, Roblox ids and account names out of every note; those stay in the private handoffs repo. The Claude Design links only open for Samarth's account.
