# Fruit Empire vault

The design notes for the Roblox game [STEAL!] Fruit Empire, kept as an Obsidian vault.

## Open it

1. Download `Fruit-Empire-Vault.zip` from the latest release and unzip it.
2. In Obsidian, choose "Open folder as vault" and pick the unzipped `Fruit Empire` folder.
3. Start at `00 Home/Fruit Empire - Home.md`.

## What is in it

| Folder | What it holds |
|---|---|
| 00 Home | The start page and links to everything else |
| 01 Vision | The brain dump the expansion design started from |
| 02 Systems | One spec per system (bats, boats and swimming, pets, potions, ...) and the review that ties them together |
| 03 Economy | The stage model (prices and rewards for each stage) and the check of the numbers |
| 04 Player Paths | Walkthroughs for different players: a first session, mid game, endgame, mobile, a combat day |
| 05 Research | Notes on other games (Sky Rivals, Steal a Pet, ...) and on Roblox's limits |
| 06 Assets | Asset requests, and the packs and effects already in the place |
| 07 UI | The UI kit inventory |
| 08 Roadmap | The build order, plus a verification note with screenshots for each milestone |
| 09 Decisions | The decisions log |
| 10 Current Game | A tour of the game's code and world as it was on 4 Oct 2026 |
| Images | Pictures the notes use |
