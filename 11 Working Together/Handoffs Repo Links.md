# Handoffs repo links

The handoffs repo is the private GitHub repo **svaka2000/fruit-empire-handoffs**. Samarth, Weilin and both Claudes read it. It holds no game code: only what changed, why, screenshots and what is next. Back to [[Knowledge Base - Start Here]].

> [!important] The repo wins
> These notes link to the repo instead of copying it, so they never go stale in two places. If a note here and the repo disagree, trust the repo. The repo itself says the same about this vault: its STATE.md calls this vault's "10 Current Game" pages out of date.

Local clone: `~/fruit-empire-handoffs`. On 8 Nov 2026 it sat on the branch `handoff/2026-10-30-samarth-pets` with a blank handoff page, because a pets turn was started on 30 Oct and not yet published. Read the pages on GitHub (main branch) for the current text.
